Most of my personal work is some form of simulation: evolutionary biology, cosmological structure formation, multi-agent neural systems where selective pressure emerges from energy economics rather than explicit fitness functions. The common thread is emergent behavior, setting up the rules and watching what the system decides to do with them.

That interest pulls naturally toward GPU compute. Pushing millions of entities through physics each frame requires thinking about memory layout, kernel design, and dispatch overhead before thinking about the simulation itself. I work with Metal and MPS on Apple Silicon, have touched CUDA, and use Taichi when I want the GPU without the boilerplate hell.
